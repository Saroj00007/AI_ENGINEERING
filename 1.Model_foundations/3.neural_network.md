# Phase 1 — Chapter 3: Neural Networks

Now we're going to take the simple model from Chapter 2:

$$
\hat y = w\cdot x+b
$$

and see how **neurons and layers** turn this basic computation into a powerful model.

The key idea is:

> **A neural network is essentially many parameterized mathematical transformations composed together.**

---

## 1. From one model to a neuron

Our previous model was:

$$
\hat y = w\cdot x+b
$$

A **neuron** performs essentially this type of computation.

For multiple inputs:

```text
x₁ ──┐
     │
x₂ ──┼──→ weighted sum → activation → output
     │
x₃ ──┘
```

Mathematically:

$$
z=w_1x_1+w_2x_2+w_3x_3+b
$$

Then we apply an **activation function**:

$$
a=f(z)
$$

So the neuron is:

```text
Inputs
  ↓
Weighted sum + bias
  ↓
Activation function
  ↓
Output
```

That's the basic building block.

---

# 2. Why do we need the activation function?

This is extremely important.

Suppose we only did:

$$
y=Wx+b
$$

and then stacked many layers:

```text
Input
 ↓
Linear transformation
 ↓
Linear transformation
 ↓
Linear transformation
 ↓
Output
```

A composition of linear transformations is still essentially a linear transformation.

So simply adding more linear layers doesn't give us the expressive power we want.

The **activation function introduces non-linearity**.

Conceptually:

```text
Linear transformation
        ↓
   Non-linearity
        ↓
Linear transformation
        ↓
   Non-linearity
        ↓
       ...
```

This allows neural networks to represent much more complicated relationships.

---

# 3. Common activation functions

You don't need to memorize every activation function right now.

The important idea is that an activation function transforms the neuron's weighted computation in a nonlinear way.

Examples include:

### ReLU

$$
f(x)=\max(0,x)
$$

So:

```text
-3 → 0
 2 → 2
 5 → 5
```

ReLU is extremely common in neural networks.

### Sigmoid

Maps values approximately into:

$$
0\rightarrow1
$$

It can therefore be useful when we want an output that behaves like a probability.

We'll encounter different activations later depending on the architecture and task.

---

# 4. From neurons to a layer

One neuron isn't very powerful.

So we have many neurons operating together:

```text
             ┌── Neuron 1 ──┐
             │              │
Input ───────┼── Neuron 2 ──┼──→ outputs
             │              │
             └── Neuron 3 ──┘
```

That's a **layer**.

For example:

```text
Input:
[ x₁ x₂ x₃ ]

        ↓

Layer:
[ neuron₁
  neuron₂
  neuron₃
  neuron₄ ]

        ↓

Output:
[ a₁ a₂ a₃ a₄ ]
```

Each neuron has its **own weights and bias**.

Therefore, the layer contains many parameters.

---

# 5. Matrix multiplication enters here

Remember our Chapter 1 discussion about matrices?

Now we can see why they're useful.

Instead of calculating every neuron individually:

$$
z_1=w_1x+b_1
$$

$$
z_2=w_2x+b_2
$$

$$
z_3=w_3x+b_3
$$

we can represent the whole layer using matrices:

$$
z=Wx+b
$$

Then:

$$
a=f(z)
$$

So a neural-network layer is essentially:

```text
Input vector
     ↓
Matrix multiplication
     ↓
Add bias
     ↓
Activation
     ↓
Output vector
```

This is one of the most important connections between your **linear algebra knowledge** and AI.

---

# 6. Multiple layers = deep neural network

Now stack layers:

```text
Input
  ↓
Layer 1
  ↓
Layer 2
  ↓
Layer 3
  ↓
Output
```

Each layer transforms the representation produced by the previous layer.

Conceptually:

```text
Raw input
   ↓
Representation
   ↓
Higher-level representation
   ↓
More complex representation
   ↓
Prediction
```

This is one reason we call it **deep learning**:

> The model has multiple layers of learned transformations.

---

# 7. Why does this actually work?

Imagine an image classifier.

Early layers might learn useful low-level patterns:

```text
edges
lines
simple shapes
```

Later layers can combine those representations into more complex patterns:

```text
textures
parts
shapes
objects
```

Eventually:

```text
complex representation
        ↓
prediction
```

We should be careful with the wording, though.

We don't manually tell the network:

> "Layer 1, learn edges."

The network learns useful internal representations through training.

That's the key idea.

---

# 8. Forward pass

When an input travels through the network to produce a prediction, that's called the **forward pass**.

For example:

```text
Input
 ↓
Layer 1
 ↓
Activation
 ↓
Layer 2
 ↓
Activation
 ↓
Layer 3
 ↓
Output
```

Mathematically, you could imagine:

$$
z_1=W_1x+b_1
$$

$$
a_1=f(z_1)
$$

Then:

$$
z_2=W_2a_1+b_2
$$

$$
a_2=f(z_2)
$$

And so on.

Eventually:

$$
\hat y = ...
$$

The important idea:

> **Forward pass = use the current parameters to transform the input into a prediction.**

---

# 9. Where does training happen?

Now connect this to Chapter 2.

During training:

```text
                FORWARD PASS
                     ↓
Input → Neural Network → Prediction
                              ↓
                             Loss
                              ↓
                         Backpropagation
                              ↓
                          Gradients
                              ↓
                      Update parameters
```

So the complete process becomes:

### Forward

> "Given my current parameters, what do I predict?"

### Loss

> "How wrong was that prediction?"

### Backpropagation

> "Which parameters contributed to the error, and how should they change?"

### Optimization

> "Update those parameters."

Then repeat.

---

# 10. What is backpropagation?

This is where many explanations become unnecessarily complicated.

You already know calculus, so here's the useful interpretation:

> **Backpropagation efficiently calculates how the loss changes with respect to the parameters throughout the network.**

Imagine:

```text
Loss
 ↓
Layer 3 parameters
 ↓
Layer 2 parameters
 ↓
Layer 1 parameters
```

Backpropagation uses the chain rule to propagate gradient information backward through the network.

So:

```text
Forward pass:
Input → Layer 1 → Layer 2 → Layer 3 → Loss

Backward pass:
Loss → Layer 3 → Layer 2 → Layer 1
```

The backward pass tells us the gradients needed to update the parameters.

You don't need to derive the chain rule here.

The key mental model is:

> **Forward pass calculates the prediction. Backpropagation calculates how the parameters should change to reduce the loss.**

---

# 11. The entire neural-network learning process

Now everything we've learned in Chapters 1–3 connects:

```text
                 TRAINING
                    │
                    ▼
              Input vector
                    │
                    ▼
              ┌───────────┐
              │  Layer 1  │
              └─────┬─────┘
                    ↓
              ┌───────────┐
              │  Layer 2  │
              └─────┬─────┘
                    ↓
              ┌───────────┐
              │  Layer 3  │
              └─────┬─────┘
                    ↓
                Prediction
                    ↓
                   Loss
                    ↓
             Backpropagation
                    ↓
                Gradients
                    ↓
          Update parameters
                    ↓
                  Repeat
```

This is the core of neural-network training.

---

## One important distinction

Don't think:

> "The neurons are individually learning."

A better mental model is:

> **The network's parameters are optimized together.**

A network may contain millions or billions of parameters, and training adjusts those parameters based on gradients from the loss.
