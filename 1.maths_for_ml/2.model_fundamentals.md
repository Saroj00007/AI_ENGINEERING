# Chapter 2 — Model Fundamentals

This is where we connect the representations from Chapter 1 to the **learning process** we understood in Phase 0.

The central question is:

> **How does a model actually use numbers to make a prediction, measure whether that prediction is bad, and improve itself?**

The core loop is:

```text
Input
  ↓
Weights + Bias
  ↓
Prediction
  ↓
Loss
  ↓
Gradient
  ↓
Update Parameters
  ↓
Repeat
```

We'll go through this one concept at a time.

---

## 1. Start with the simplest possible model

Suppose we're trying to predict house prices.

We have one input:

```text
x = house size
```

and want to predict:

```text
y = house price
```

Our simplest model could be:

$$
\hat{y} = wx
$$

Where:

* `x` = input
* `w` = parameter/weight
* `ŷ` = model's prediction

Suppose:

```text
x = 5
w = 2
```

Then:

$$
\hat{y}=2(5)=10
$$

The model predicts:

```text
10
```

### Where does `w = 2` come from?

This is the important part.

We don't necessarily manually choose `w`.

During **training**, the model learns an appropriate value for `w`.

This connects directly to Phase 0:

> **Training = repeatedly adjusting parameters so the model's behavior improves according to an objective.**

---

# 2. What is a weight?

A **weight is a learned parameter that controls how strongly an input influences a computation.**

Suppose:

$$
y = w_1x_1+w_2x_2
$$

Maybe:

```text
x₁ = house size
x₂ = number of bedrooms
```

Then:

```text
w₁ = 0.8
w₂ = 0.3
```

The model is effectively saying:

> "For this learned function, these inputs contribute with these strengths."

The important thing is that **the weights are learned during training**.

---

# 3. Bias

Now consider:

$$
\hat y = wx+b
$$

We've added:

$$
b
$$

which is the **bias**.

Why?

Because sometimes the model needs to shift its output independently of the input.

For example:

```text
w = 2
b = 3
x = 5
```

Then:

$$
\hat y = 2(5)+3=13
$$

Think of it intuitively as:

> **Weight controls the influence/slope; bias provides an adjustable offset.**

We'll see why this becomes important when we get to neural-network layers.

---

# 4. From one input to vectors

Now connect this with Chapter 1.

Instead of:

$$
y=wx+b
$$

we can have:

$$
\hat y = w \cdot x+b
$$

where both `w` and `x` are vectors.

For example:

```text
x = [2, 3, 4]

w = [0.5, 0.2, 0.8]
```

The model performs a dot product:

$$
w\cdot x
$$

So:

```text
0.5×2 + 0.2×3 + 0.8×4
```

and then adds the bias.

This is the connection between **Chapter 1's dot product** and **actual model computation**.

---

# 5. But how does the model know whether its prediction is good?

Suppose the correct answer is:

```text
y = 20
```

but our model predicted:

```text
ŷ = 13
```

We need some way to measure:

> **How wrong is the prediction?**

That's the job of the **loss function**.

For a simple example, we could use squared error:

$$
L=(y-\hat y)^2
$$

Here:

$$
L=(20-13)^2=49
$$

So the model has a loss of:

```text
49
```

The exact loss function depends on the task.

The important concept is:

> **Loss converts prediction error into a numerical signal that training can use to improve the parameters.**

---

# 6. The model's learning loop

Now we can see the first real ML training loop:

```text
Input
  ↓
Model with current weights
  ↓
Prediction
  ↓
Compare prediction with target
  ↓
Calculate loss
  ↓
Determine how parameters should change
  ↓
Update parameters
  ↓
Try again
```

For example:

### Before training

```text
w = 1

x = 5
target = 20

prediction = 5
```

Bad prediction.

Training calculates the loss and determines that the parameters need to change.

Maybe after an update:

```text
w = 2
```

Now:

```text
prediction = 10
```

Still wrong, but better.

Another update:

```text
w = 3.5
```

Now:

```text
prediction = 17.5
```

Better.

Eventually the model may reach something close to the desired relationship.

**That's the fundamental idea behind parameter learning.**

---

# 7. Where does the gradient come in?

This is where your calculus knowledge becomes useful.

We don't need to relearn derivatives.

The important AI question is:

> **What information does the gradient give us?**

The gradient tells us approximately:

> **If I change this parameter, which direction will make the loss decrease, and how sensitive is the loss to that parameter?**

So conceptually:

```text
Loss
 ↓
Gradient
 ↓
Direction for parameter update
 ↓
New parameters
 ↓
Lower loss
```

This is why calculus matters in ML.

Not because we're interested in doing derivatives for their own sake.

We're using derivatives to answer:

> **How should the model's parameters change?**

---

# 8. Gradient descent

A simplified parameter update looks like:

$$
w_{\text{new}}
=
w_{\text{old}}
-
\eta
\frac{\partial L}{\partial w}
$$

Where:

* `w` = parameter
* `L` = loss
* `∂L/∂w` = gradient of loss with respect to the parameter
* `η` = learning rate

You already know the calculus.

The AI interpretation is what matters:

```text
gradient
   ↓
tells us direction
   ↓
learning rate
   ↓
controls step size
   ↓
update parameter
```

---

# 9. Learning rate

Suppose the gradient says:

> "Move this parameter in this direction."

How far should we move?

That's controlled by the **learning rate**.

### Too small

```text
parameter
   ↓
tiny update
   ↓
tiny update
   ↓
tiny update
   ↓
training can be very slow
```

### Too large

```text
parameter
   ↓
huge update
   ↓
overshoot
   ↓
huge update
   ↓
training may become unstable
```

So:

> **Learning rate controls the size of parameter updates during optimization.**

---

# 10. The complete picture

Now connect everything we've learned:

```text
                 TRAINING
                    │
                    ▼
              Training data
                    │
                    ▼
              Input vector x
                    │
                    ▼
          Weights + Bias
                    │
                    ▼
               Prediction
                    │
                    ▼
                  Loss
                    │
                    ▼
                Gradient
                    │
                    ▼
          Update parameters
                    │
                    └───────────┐
                                │
                                ▼
                         Repeat many times
```

Eventually we have:

```text
learned parameters
       ↓
trained model
```

Then during inference:

```text
New input
    ↓
Fixed learned parameters
    ↓
Prediction
    ↓
Output
```

Notice something important:

**Training and inference are fundamentally different.**

During training:

> Parameters are being updated.

During normal inference:

> Parameters are being used, not continuously learned.

That distinction will remain extremely important when we later study LLMs.

---

## Your mental model after Chapter 2

You should now be able to look at:

$$
\hat y = w\cdot x+b
$$

and see much more than an equation:

> **`x` is the input representation, `w` contains learned parameters that determine how inputs influence the prediction, `b` provides an offset, and the resulting prediction is evaluated with a loss. Gradients tell training how to modify the parameters, while the learning rate controls the size of those updates.**

That is the foundation of **optimization and neural-network learning**.

### Next part of Chapter 2

We'll go deeper into **parameters vs weights vs bias, loss functions, optimization, and gradient descent**, including a tiny numerical training example so you can see the parameter update happen rather than just hearing the theory.


Let's do the **tiny numerical training example**. This is the part where the whole Chapter 2 starts to click.

## 1. Our tiny model

We'll use the simplest possible model:

$$
\hat y = wx
$$

Suppose our training data is:

| Input `x` | Correct output `y` |
| --------: | -----------------: |
|         1 |                  2 |
|         2 |                  4 |
|         3 |                  6 |

There is an obvious relationship:

$$
y=2x
$$

But **we will pretend the model doesn't know that**.

Let's initialize the parameter randomly:

$$
w=0.5
$$

So the model currently believes:

$$
\hat y=0.5x
$$

---

## 2. First prediction

Take the first example:

$$
x=1,\quad y=2
$$

Model:

$$
\hat y=wx
$$

Therefore:

$$
\hat y=0.5(1)=0.5
$$

The model predicted:

```text
prediction = 0.5
actual     = 2
```

Clearly wrong.

---

## 3. Calculate the loss

Let's use squared error:

$$
L=(y-\hat y)^2
$$

Therefore:

$$
L=(2-0.5)^2
$$

$$
L=2.25
$$

So:

```text
Prediction → 0.5
Target     → 2
Loss       → 2.25
```

The loss tells us **how bad the current prediction is**.

But there's a problem:

> Knowing the loss is 2.25 doesn't directly tell us how to change `w`.

That's where the gradient comes in.

---

# 4. Calculate the gradient

Our model is:

$$
\hat y=wx
$$

and our loss is:

$$
L=(y-wx)^2
$$

The derivative with respect to `w` is:

$$
\frac{\partial L}{\partial w}
=
-2x(y-wx)
$$

For our example:

```text
x = 1
y = 2
w = 0.5
```

So:

$$
\frac{\partial L}{\partial w}
=
-2(1)(2-0.5)
$$

$$
=-3
$$

The gradient is:

$$
-3
$$

### What does `-3` actually mean?

Don't think:

> "I calculated a derivative."

Think:

> **The loss would decrease if we increase `w`.**

The negative sign gives us the direction.

---

# 5. Update the parameter

Gradient descent:

$$
w_{new}=w_{old}-\eta\frac{\partial L}{\partial w}
$$

Suppose our learning rate is:

$$
\eta=0.1
$$

Then:

$$
w_{new}
=
0.5-(0.1)(-3)
$$

$$
w_{new}=0.8
$$

So our parameter changed:

```text
Before:
w = 0.5

After:
w = 0.8
```

This is **learning**.

Nothing magical happened.

The model simply used the loss and gradient to change its parameter.

---

# 6. Try again

Now:

$$
w=0.8
$$

For:

$$
x=1
$$

prediction:

$$
\hat y=0.8(1)=0.8
$$

Previously:

```text
prediction = 0.5
```

Now:

```text
prediction = 0.8
```

We're closer to:

```text
target = 2
```

The model improved.

---

# 7. Repeat

Training essentially keeps doing:

```text id="b7a1e2"
                 ┌───────────────┐
                 │               │
                 ▼               │
              Input             │
                 ↓               │
             Prediction         │
                 ↓               │
                Loss            │
                 ↓               │
              Gradient           │
                 ↓               │
          Update parameter       │
                 │               │
                 └───────────────┘
```

Over many iterations, `w` should move toward approximately:

$$
w=2
$$

because that's the relationship present in our data.

Eventually:

$$
\hat y\approx2x
$$

---

# 8. Now understand the roles

This is the important part.

### Parameter

`w`

> The value the model learns.

### Prediction

`ŷ`

> What the model currently thinks the answer should be.

### Loss

`L`

> How wrong the prediction is according to our chosen objective.

### Gradient

$$
\frac{\partial L}{\partial w}
$$

> How changing the parameter affects the loss, giving us the direction for improvement.

### Learning rate

`η`

> How large a step we take when changing the parameter.

### Optimization

The overall process of finding parameter values that produce better results.

---

# 9. One important correction to our intuition

You might be tempted to say:

> "The model sees the target 2 and changes `w` directly toward 2."

That's **not really what happens**.

The model doesn't simply say:

```text
target = 2
therefore w = 2
```

Instead:

```text
current parameters
       ↓
prediction
       ↓
loss
       ↓
gradient
       ↓
parameter update
```

And this happens repeatedly across training examples.

That's why we call it **optimization**.

---

# 10. Now scale this up

Our example had:

```text
1 parameter
```

A real neural network can have:

```text
millions/billions of parameters
```

Conceptually, however, the same idea remains:

```text
Input
  ↓
Millions of parameters
  ↓
Prediction
  ↓
Loss
  ↓
Gradients
  ↓
Millions of parameter updates
  ↓
Repeat
```

The mathematics and architecture become vastly more complicated, but the fundamental learning loop remains.

This is one of the most important first-principles ideas in AI:

> **A neural network is not "thinking" in the human sense. Training is an optimization process that adjusts a large collection of numerical parameters so the model performs better according to an objective.**

---

## One more concept: parameters vs hyperparameters

This distinction is important.

### Parameters

Learned **by the model**:

```text
weights
biases
```

### Hyperparameters

Chosen/configured **by us**:

```text
learning rate
batch size
number of layers
number of neurons
number of training epochs
```

For example:

```text
learning rate = 0.001
```

is **not learned by the model through gradient descent** in the basic setup.

We choose it.

Whereas:

```text
weight = 0.734...
```

is learned during training.

### Easy mental distinction

> **Parameters are what the model learns.**
> **Hyperparameters are settings we use to control how the model learns.**
