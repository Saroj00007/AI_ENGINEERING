## 1. Where are we in the Transformer?

Recall the simplified flow we've studied:

$$
\text{Token Embeddings}
\rightarrow \text{Positional Information}
\rightarrow \text{Self-Attention}
$$

After attention, each token has a representation that incorporates information from other relevant tokens.

Consider:

> The animal didn't cross the street because it was tired.

When processing the word *it*, attention might help the model gather information from *animal* and other relevant words.

But here's an important question:

**After gathering information from other tokens, how does the model further process and transform that information?**

That's where the Feed-Forward Network comes in.

A simplified Transformer block contains:

$$
\boxed{
\text{Self-Attention}
\rightarrow
\text{Feed-Forward Network}
}
$$

In practice, we also need residual connections and layer normalization, which we'll introduce shortly.

## 2. Feed-Forward Network (FFN)

### 2.1 The core idea

Think about the two operations we've discussed:

* **Self-attention:** Allows tokens to gather and combine information from other tokens.
* **Feed-forward network:** Processes the information in each token's representation through learned transformations.

Attention focuses on how information is exchanged between token positions.

The FFN transforms the resulting representations.

One useful analogy is:

* Attention gathers relevant information from different sources.
* The FFN processes the gathered information.

This analogy is helpful, although the actual computations are mathematical transformations rather than explicit human-like reasoning.

### 2.2 How does an FFN work?

A common Transformer FFN uses two linear transformations with a nonlinear activation function between them.

Its simplified equation is:

$$
\boxed{\operatorname{FFN}(x)=W_2\,\operatorname{GELU}(W_1x+b_1)+b_2}
$$

Let's understand each part.

**Step 1: Input representation**

Suppose a token has a representation containing 4 numbers:

$$
x=[0.2,\ 0.5,\ -0.1,\ 0.8]
$$

These numbers are learned features in the token's representation. We shouldn't assume that each number has a simple, individually understandable meaning.

**Step 2: First linear transformation**

The FFN transforms the representation into a larger intermediate vector.

For example:

$$
4\text{ dimensions}\rightarrow 16\text{ dimensions}
$$

It does this using a learned weight matrix and bias:

$$
h=W_1x+b_1
$$

The model learns the values in \(W_1\) and \(b_1\) during training.

Why expand the dimensions?

A larger intermediate representation gives the network more capacity to express complex transformations.

**Step 3: Apply a nonlinear activation**

Next, we apply an activation function, such as GELU:

$$
h'=\operatorname{GELU}(h)
$$

Why introduce nonlinearity?

Without nonlinear activation functions, stacking linear transformations would still be equivalent to a single linear transformation. Nonlinearity lets the network learn more complex functions.

You don't need to memorize the GELU formula right now. Just remember that it introduces nonlinearity into the transformation.

**Step 4: Project back to the original dimension**

The second linear transformation maps the intermediate vector back to the model's original dimension:

$$
16\text{ dimensions}\rightarrow 4\text{ dimensions}
$$

The result is a new representation of the token.

Therefore, our example FFN follows:

$$
\boxed{4\rightarrow16\rightarrow4}
$$

Real models often use much larger dimensions. For example, a model might have a hidden dimension of 768 and an FFN intermediate dimension of 3072.

The specific dimensions depend on the architecture.

### 2.3 Does the FFN process all tokens together?

This is an important distinction.

Suppose the input contains five token representations:

$$
X\in\mathbb{R}^{5\times4}
$$

That means there are five tokens, each represented by four numbers.

The FFN applies the same learned transformation independently to each token position:

$$
\underbrace{5\times4}_{\text{input}}
\rightarrow
\underbrace{5\times16}_{\text{intermediate}}
\rightarrow
\underbrace{5\times4}_{\text{output}}
$$

The sequence length remains five.

Unlike self-attention, the standard FFN doesn't directly exchange information between different token positions. It processes each token's representation separately, using the same weights at every position.

**Key distinction:**

| Component            | Primary role                                                           |
| -------------------- | ---------------------------------------------------------------------- |
| Self-attention       | Exchanges information between token positions                          |
| Feed-forward network | Applies learned nonlinear transformations to each token representation |

Together, they let the Transformer repeatedly exchange and process information.

## 3. Residual Connections

Now we encounter a different problem.

Imagine that a token already has a useful representation. We pass it through a complex transformation, but the transformation initially produces an unhelpful result.

How can the network preserve access to the original representation while learning the transformation?

One solution is a **residual connection**, also called a skip connection.

### 3.1 The basic idea

Instead of using only the output of a transformation, we add the original input to that output.

Mathematically:

$$
\boxed{y=x+F(x)}
$$

Here:

* \(x\) is the original input.
* \(F(x)\) is the result of a learned transformation.
* \(y\) is the result after adding the original input back.

For example, suppose:

$$
x=[2,3]
$$

and the transformation produces:

$$
F(x)=[0.5,-1]
$$

The residual output is:

$$
y=[2,3]+[0.5,-1]
$$

Therefore:

$$
\boxed{y=[2.5,2]}
$$

The original representation is carried forward alongside the transformation's contribution.

### 3.2 Why is this useful?

Residual connections are especially important in deep neural networks.

They provide a direct path for information and gradients to flow through the network, which can make optimization easier.

Without residual connections, training a very deep network can become more difficult because gradients may become extremely small or large as they propagate through many layers.

Residual connections help address this problem, although they don't guarantee that training will always be stable.

### 3.3 How does a residual connection work with attention?

Conceptually, consider an attention sublayer receiving an input \(X\).

The attention operation produces:

$$
A=\operatorname{Attention}(X)
$$

A residual connection combines the original input with the attention output:

$$
\boxed{Y=X+A}
$$

This assumes the dimensions are compatible, as they are in standard Transformer blocks.

The attention output can contribute new information, while the original representation has a direct path forward.

A similar residual connection is used around the FFN.

**Important:** A residual connection isn't another neural network that learns a separate set of weights. The addition itself has no trainable parameters.

## 4. Layer Normalization

Residual connections help preserve information and improve gradient flow. But we also need a way to manage the numerical behavior of the representations flowing through the network.

This brings us to **Layer Normalization**, commonly called *LayerNorm*.

### 4.1 The core idea

A token representation might look like this:

$$
x=[2,\ 100,\ -5,\ 30]
$$

Its components have different values and scales.

LayerNorm normalizes the features of a representation using its mean and variance.

For a single token representation with \(d\) features, we calculate the mean:

$$
\mu=\frac{1}{d}\sum_{i=1}^{d}x_i
$$

Then calculate the variance:

$$
\sigma^2=\frac{1}{d}\sum_{i=1}^{d}(x_i-\mu)^2
$$

We normalize each component:

$$
\hat{x}_i=\frac{x_i-\mu}{\sqrt{\sigma^2+\epsilon}}
$$

Here, \(\epsilon\) is a small constant used for numerical stability.

Finally, LayerNorm applies learned scale and shift parameters:

$$
\boxed{y_i=\gamma_i\hat{x}_i+\beta_i}
$$

where:

* \(\gamma_i\) is a learned scaling parameter.
* \(\beta_i\) is a learned shifting parameter.

This final step allows the model to learn an appropriate scale and offset for each feature.

You don't need to memorize the equations yet. Understand the sequence:

**Calculate statistics → normalize features → apply learned scale and shift.**

### 4.2 What does LayerNorm normalize?

In a standard Transformer, LayerNorm generally normalizes across the feature dimension of each token representation, rather than calculating one shared mean and variance across all tokens in the sequence.

For example, if:

$$
X\in\mathbb{R}^{5\times4}
$$

then each of the five token representations has four features.

LayerNorm calculates normalization statistics across those four features for each token independently.

It does not mix information between token positions.

### 4.3 Why do we need LayerNorm?

LayerNorm helps control the scale and numerical behavior of activations as they flow through a deep network. This often makes training more stable.

However, LayerNorm doesn't simply force every activation to be small, nor does it guarantee perfect stability.

Also, LayerNorm and residual connections serve different purposes:

* **Residual connection:** Adds the input to a transformation's output.
* **LayerNorm:** Normalizes a representation and applies learned scale and shift.

They often work together, but they aren't interchangeable.

## 5. How do these components fit together?

Let's assemble the pieces.

A Transformer block needs to:

1. Let tokens exchange information through attention.
2. Preserve a direct path for the original representations.
3. Normalize the resulting representations.
4. Apply nonlinear transformations through the FFN.
5. Again preserve a direct path and normalize the result.

One common design is the **Post-LayerNorm Transformer block**:

$$
A=\operatorname{Attention}(X)
$$

$$
H=\operatorname{LayerNorm}(X+A)
$$

$$
F=\operatorname{FFN}(H)
$$

$$
\boxed{Y=\operatorname{LayerNorm}(H+F)}
$$

Read this as:

**Input → Attention → Add original input → Normalize → FFN → Add previous representation → Normalize → Output**

This is a simplified representation of the architecture.

Modern GPT-style models commonly use a different arrangement called **Pre-LayerNorm**, where normalization is applied before the attention and FFN transformations. We'll examine the architectural differences in Chapter 7.

For now, focus on the roles of the components rather than memorizing one particular ordering.

### The complete picture

| Component            | What it contributes                                              |
| -------------------- | ---------------------------------------------------------------- |
| Self-attention       | Allows tokens to gather information from other positions         |
| Feed-forward network | Applies nonlinear transformations to each token's representation |
| Residual connection  | Adds the original input to the transformed output                |
| LayerNorm            | Normalizes features and applies learned scaling and shifting     |

Together, these components form the computational core of a Transformer block.

A model stacks many such blocks. At each layer, token representations can become progressively more useful for predicting the next token.

## 6. Industry perspective: What should an AI engineer understand?

When reading model architectures or documentation, you should be able to answer these questions:

* **Why does the model have an FFN?** Attention and FFN perform complementary computations: information exchange and nonlinear transformation.
* **Why are residual connections used?** They provide direct information and gradient paths through deep networks.
* **Why is LayerNorm used?** It helps manage activation scales and supports stable optimization.
* **Why does the FFN expand and then shrink the representation?** The larger intermediate dimension provides additional capacity while preserving the model's expected output dimension.
* **Does every Transformer use exactly the same design?** No. Details such as normalization placement, activation function, and FFN structure vary across architectures.

These are more useful than memorizing equations without understanding their purpose.
