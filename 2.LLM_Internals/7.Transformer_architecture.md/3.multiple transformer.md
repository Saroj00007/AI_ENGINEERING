### Where we stopped

We were discussing why a Transformer needs both **self-attention and a feed-forward network (FFN)**.

Remember the distinction:

* **Self-attention:** Allows each token to incorporate information from other tokens.
* **FFN:** Transforms the token's existing features into a new representation using learned nonlinear transformations.
* **Residual connections:** Preserve a direct path for existing information and gradients.
* **Layer normalization:** Normalizes feature values to help the network train reliably.

For example, after processing:

> The cat chased the mouse.

Self-attention allows the representation of `cat` to incorporate information from `chased` and `mouse`. The FFN then transforms the resulting representation into a different set of learned features.

The FFN doesn't produce a word or retrieve a complete fact. It helps the network develop useful representations for subsequent processing.

## Chapter 7 — Part 2: How Transformer Blocks Stack Together

Now let's understand how these components form a complete Transformer.

Imagine a simplified GPT with **12 Transformer blocks**.

Each block contains attention and an FFN, along with residual connections and normalization.

Conceptually, the architecture looks like this:

```text
Input text
    ↓
Tokenization
    ↓
Token IDs
    ↓
Token Embeddings + Positional Information
    ↓
┌──────────────────────────────┐
│ Transformer Block 1           │
│                              │
│  Self-Attention               │
│       ↓                      │
│  Residual + LayerNorm         │
│       ↓                      │
│  Feed-Forward Network         │
│       ↓                      │
│  Residual + LayerNorm         │
└──────────────────────────────┘
    ↓
┌──────────────────────────────┐
│ Transformer Block 2           │
│                              │
│  Self-Attention               │
│       ↓                      │
│  Residual + LayerNorm         │
│       ↓                      │
│  Feed-Forward Network         │
│       ↓                      │
│  Residual + LayerNorm         │
└──────────────────────────────┘
    ↓
           ...
    ↓
┌──────────────────────────────┐
│ Transformer Block 12          │
└──────────────────────────────┘
    ↓
Final hidden representations
    ↓
Language-model head
    ↓
Logits → Probabilities
    ↓
Select the next token
```

*This illustrates a simplified Post-LayerNorm arrangement. Many modern GPT-style models use Pre-LayerNorm or related variants, but the overall idea of stacking Transformer blocks remains the same.*

### 1. Why stack multiple blocks?

Suppose the input is:

> The animal didn't cross the road because it was too ...

To predict the next token, the model needs to process the relationships among words and the context of the sentence.

A single Transformer block can already combine information through attention and transform features through its FFN.

But **one block may not be sufficient to develop the useful representations the model needs for every task**.

Stacking blocks allows representations to undergo repeated rounds of contextual processing and feature transformation.

For example, conceptually:

* **Earlier blocks:** May develop useful local patterns and basic relationships.
* **Middle blocks:** May combine information into more complex contextual representations.
* **Later blocks:** May refine representations useful for predicting the next token.

These are tendencies, not strict rules. We shouldn't assume that every layer has one specific, clearly defined job.

### 2. What actually travels between blocks?

This is an important point.

The blocks don't pass words such as `"animal"` or `"road"` to one another.

They pass **numerical representations**.

Imagine that one token has a hidden representation with 4 dimensions:

```text
Block 1 output:
[0.2, 0.7, -0.1, 0.5]
          ↓
       Block 2
          ↓
Block 2 output:
[0.4, 0.3,  0.8, 0.1]
          ↓
       Block 3
          ↓
Block 3 output:
[0.6, -0.2, 0.5, 0.9]
```

These values are illustrative, not real model outputs.

Notice that the vector's dimension remains 4 in this example, even though its values change.

Each block transforms the representations it receives. Those representations carry information about the token and the context processed so far.

Also, each token has its own representation at every layer; the vectors above illustrate just one token's journey.

### 3. Does each block learn separately?

Each block has its own learned parameters.

For example:

```text
Block 1 → Attention parameters A₁, FFN parameters F₁
Block 2 → Attention parameters A₂, FFN parameters F₂
Block 3 → Attention parameters A₃, FFN parameters F₃
```

These parameters are generally different across blocks.

During training, the model makes predictions, calculates its loss, and uses backpropagation and an optimizer to update parameters throughout the network.

The blocks are trained **together as one model**, rather than each block independently learning a separate language model.
